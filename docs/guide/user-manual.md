# 记忆助手 · 用户使用手册

> 写给不想碰命令、只想把「记忆」用起来的人。全程在界面里点，不需要输入任何命令。
> 需要安装命令、接口或二次开发，请让技术同事看 [开发者手册](developer-manual.md)。

## 它帮你做什么

你的 AI 助手每次开新对话都会「失忆」。这套记忆给它一个长期记事本：

- 你们确认过的事实、踩过的坑、总结出的经验，会一条条存下来；
- 下次开新对话，助手仍然知道；
- 每条记忆有标题和正文，改一条会留下旧版本，不会悄悄覆盖；
- 记忆存在你自己的电脑上，不上传云端。

记忆分三类：

| 类型 | 适合记什么 |
|---|---|
| 事实 | 稳定成立的知识、约定、结论 |
| 坑 | 容易犯的错误，以及触发它的特征（比如某个报错关键字） |
| 经验 | 一套做法、流程、技巧 |

## 安装

1. 不用自己准备安装包：可以直接粘贴 tgz 的**下载链接**，也可以让助手从 GitHub 下载（见下方提示词）；
2. 打开 DSH，点左侧栏「插件」→「添加插件」（或「设置 → 插件」）；
3. 粘贴下载链接或本地文件路径，点「安装」；
   - **不需要 pnpm**：插件页用的是 DSH 自带的包管理器；
4. 安装完成后，**完整退出 DSH 再打开**（托盘图标也要退出，不是只关窗口）；
5. 左侧栏出现「记忆」图标，就装好了。

> 不想点界面时，可以把[安装手册](install.md) §4 的提示词贴进聊天框，让助手从 GitHub 下载并代装；它会在需要重启前提醒你。

> 不需要注册账号，也不需要联网保存记忆。

## 升级

1. 打开「记忆」页面，进入「偏好与规则」；
2. 在「插件更新」里点「检查更新」——只有你点的时候才会联网；
3. 如果有新版本，点「升级到 x.y.z」；
4. 升级完成后，**完整退出 DSH 再打开**，新版本才会生效。

如果页面提示“请在设置 → 插件中更新”，说明当前环境不允许插件自己安装；按安装步骤重新装一次新版本即可。升级不会动你的记忆，不需要重新导入。

## 第一次打开

点左侧栏的「记忆」，你会看到：

- 顶部是标题和数量；
- 中间是搜索框和几个按钮；
- 下面按「事实 / 坑 / 经验」分组列出记忆；
- 每条前面的编号（如 F-01、P-01、E-01）只是为了方便口头指代，不是内部编号。

## 让助手记住一件事

直接对助手说：

> 记住：部署前必须先跑数据库迁移，否则启动会报错。

助手会先给你一张**确认卡片**，上面写着它准备记什么、为什么、引用你哪句话。

- 点「采纳」：写入记忆；
- 点「驳回」：不写；
- 点「暂不处理」：提案先留着，以后再说。

助手不能自己批准自己的改动，最后一步永远由你点。

## 改一条、删一条

在列表里点开一条记忆：

- 可以修改摘要和正文，修改同样会先弹卡片；
- 删除是**彻底删除**：文件会移除，旧版本也一起清掉；删除记录只保留「已删除」这件事，不保留正文；
- 删错了无法从界面恢复，重要内容请先做备份。

## 搜索和看详情

- 顶部搜索框输入关键词，点「搜索」；
- 点任意一条记忆，可以看它的正文；
- 在项目工作树里，顶部详情卡只显示标题，标签和关系在下面编辑。

## 项目工作树

点工具栏的「项目」，进入项目视图：

### 第一层：项目总览

- 每个项目一张卡片，显示记忆数、最近更新、相似提示数量；
- 点「＋ 新建项目」，输入名称即可创建；
- 点项目卡片进入该项目；
- 项目卡片上的「删除项目」只删除这个项目框：**里面的记忆不会被删除**，会回到「未归类」；以后重建同名项目，它们会重新归入。

### 第二层：项目里的记忆

进入项目后，左侧按事实/坑/经验分组，右侧是关系图区域：

- 点左侧一条记忆，顶部会出现它的标题卡；
- 每条记忆前面的小方框可以勾选，勾选多条后，右上角选「移动到…」，可以一次移动到别的项目或「未归类」；
- 「全选」可以一次勾选当前项目的全部记忆。

### 第三层：局部关系图

- 点一条记忆后，右侧会显示它与同项目相关记忆的关系图；
- 实线表示你手动添加的关系；
- 虚线表示「同项目、同标签」的提示关系；
- 如果什么关系都没有，会显示一句说明，不会只画一个孤零零的圆。

## 给记忆加标签和关系

进入项目，点一条记忆，顶部标题卡下面有「标签 / 关系」：

**标签**

- 用逗号分隔，例如「v4, 界面, 发布」；
- 点「保存标签」；
- 最多 8 个，每个不超过 32 个字；
- 标签会影响相似提示和关系图里的虚线。

**关系**

- 先选类型：「相关」表示内容相关，「来源」表示这条是从另一条衍生出来的；
- 再选同项目里的目标记忆；
- 点「添加关系」；
- 已添加的关系会显示成一枚小标签，点后面的「×」可以删除。

关系只用于工作树和关系图，不会改记忆正文，也不会自动新建记忆；添加和删除都会留下审计记录。

## 处理助手的提案

助手想新增、修改或删除记忆时，会先进入「提案」：

- 点右上角「提案」查看；
- 卡片上写着：改哪条、为什么、改成什么；
- 点「采纳」才生效，点「驳回」就丢弃；
- 你不在时提案会留着，不会自动生效。

## 偏好、规则和「人设」

右上角「偏好与规则」里可以编辑：

- **偏好**：关于你的长期习惯，比如称呼、工作方式；
- **规则**：必须遵守的约定，保存后会立即生效并加上防篡改校验；
- 同一页会显示「人设文件」的位置，但插件不会读取或修改它的内容；你改完点「一键封存」即可。

## 备份和换电脑

- 「导出备份」：下载一个备份文件；
- 「导入备份」：选择之前导出的文件；
- 导入时按内容去重，重复的记忆会跳过，不会产生两份；
- 换电脑时，先导出，再到新电脑导入即可。

## 隐私和边界

- 记忆存在本机，不需要账号，也不上传云端；
- 不要往记忆里放密码、密钥、证件号等敏感信息；系统会拦明显像密钥的内容，但不要依赖它；
- 助手只能「提议」，不能替你采纳；删除和彻底清除也只能由你执行；
- 默认每次写入都会先问你；如果你在设置里把权限改成更自动的模式，删除仍然只能由你做。

## 常见问题

**侧栏没有「记忆」图标？**
确认插件已启用，然后完整退出 DSH 再打开。还不行就让技术同事看开发者手册的安装排查。

**点了记忆没有反应？**
先看顶部是否出现标题卡；如果列表能点、标题卡不出现，可能是插件版本旧，重新安装最新版本再试。

**提案卡片没出现？**
提案会保留。打开「记忆 → 提案」仍可以处理。

**改完内容为什么旧版本还在？**
这是故意的：修订生成新版本，旧版本保留可查，避免误改后找不回来。

**删除和彻底清除有什么区别？**
普通删除让记录失效但历史可查；彻底清除会移除文件，无法恢复。界面上的「删除」是彻底删除，操作前请确认。

**记忆存在哪里？**
存在你这台电脑上，由插件管理；不需要你手动找文件，换机用备份即可。
