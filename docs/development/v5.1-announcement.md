# Agent Memory V5.1 更新公告（0.5.1）

> 2026-10-18 · 适用 DSH 桌面 0.2.1-rc.2+ · 包名 `@agent_memory/dsh@0.5.1`

V5.1 回答一个很实际的问题：**装了旧版，怎么知道有新版、怎么不用命令行升级。**

## 一、检查更新

设置页新增“插件更新”：

- 点“检查更新”才联网，不后台轮询；
- 查 npm 主 registry，失败回退 npmmirror；
- 显示当前版本、最新版本；没有更新就直说；
- 离线/网络失败只影响这次检查，不影响记忆。

## 二、一键升级

- 有新版时出现“升级到 x.y.z”；
- 点击后由宿主插件管理器安装精确版本；
- 安装完成提示**完整重启 DSH**；
- 宿主没有插件管理服务时，会明确让你去“设置 → 插件”手动更新，不假装成功。

## 三、安全边界

- 不会静默下载、不会自动重启；
- 只接受精确 `x.y.z`，拒绝任意 URL/包名；
- 不改数据目录；升级失败保持原版本。

## 四、已知限制

- Desktop 的包安装归 Desktop shell 所有；某些 profile 可能只支持手动安装。
- 检查更新依赖外网；内网/离线环境会提示失败。
- 升级后必须重启 DSH，当前进程不会热替换插件代码。

## 五、验证

`npm run ci`、`node scripts/stage.mjs S7`、`npm run smoke`、`npm run pack`；`mem verify --deep`。
