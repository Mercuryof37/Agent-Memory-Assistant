# Agent Memory V5.0 更新公告（0.5.0）

> 2026-10-18 · 适用 DSH 桌面 0.2.1-rc.2+ · 包名 `@agent_memory/dsh@0.5.0`

V5.0 的主题是**长期可用**：审计可归档、启动不读全史、崩溃可校验、批量导入能跑 10k。

## 一、审计与存储

- **checkpoint**：`.state/checkpoint.json` 保存 journal head、文档哈希、Merkle root；默认 HMAC-SHA256。
- **尾部启动**：只读 checkpoint 之后的 journal；旧段不再全量重放。
- **归档**：活跃 journal 超过 50k 行后自动归档旧段为 gzip + 元数据；默认保留 365 天，超期可只留 root。
- **`mem maintain`**：手动触发 checkpoint/归档/保留清理。

## 二、可靠性

- **`mem verify [--deep]`**：校验 checkpoint HMAC、journal 链、归档 sha256/seq/Merkle。
- HMAC 密钥缺失时**只读**，不再悄悄生成新密钥。
- 归档先写索引、再删原段，缩小崩溃窗口。
- 崩溃点测试覆盖写文件前/写 journal 前/派生文件前。

## 三、性能

| 场景 | 结果 |
|---|---|
| 1000 条 recall P95 | ~2.3 ms |
| 1000 条逐条写入 | ~30 ms/条 |
| 10k 批量导入 | 26.2s（2.62 ms/条） |
| 10k 并发 group commit | 24.3s（2.43 ms/条） |
| 10k reload | ~0.6s |

**边界**：顺序逐条同步写入仍每条 fsync；group commit 需要并发提交，批量导入用 `addMany`。

## 四、升级

- 旧库可直接用：没有 checkpoint 时走原 journal 全量读取，首次 checkpoint 自动生成。
- 新增 `.state/checkpoint.key`，请与数据目录一起备份；丢失时删除 checkpoint 可回退全量读取。
- 回滚到 0.4.0 不会删除记忆文件或 journal。

## 五、验证

`npm run ci`、`node scripts/stage.mjs S5`、`npm run smoke`、`npm run pack`；10k 结果见 `docs/plan/v5-robustness.md`。
