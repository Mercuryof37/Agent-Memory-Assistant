# ADR-0027 · Chrome 配色与详情出处移除

- 状态：已实现（待真实桌面复验）
- 日期：2026-10-18
- 阶段：V3.0 视觉修正
- 依据：[ADR-0026](0026-v3-visual-tokens.md)

## 问题

首版 `am-*` 用了暖灰底 + 靛蓝强调，和宿主/桌面环境放一起显得偏色；详情里的「用户 #7277：…」对话出处对普通用户没有意义，占了正文之后的视线。

## 选择

1. **换成 Chrome 调色板**：
   - 浅色：页面 `#f8f9fa`、卡片 `#fff`、文字 `#202124`、次要 `#5f6368`、边框 `#dadce0`、强调 `#1a73e8`、危险 `#d93025`、成功 `#188038`；
   - 深色：页面 `#202124`、卡片 `#292a2d`、文字 `#e8eaed`、次要 `#9aa0a6`、边框 `#3c4043`、强调 `#8ab4f8`；
   - 三类色：事实 `#1a73e8` / 坑 `#b06000` / 经验 `#188038`，配 Chrome 风格的浅底软标签；
   - 字体栈加 `Roboto`（宿主没有时回退 Segoe UI/Arial/微软雅黑）；圆角 8/12。
2. **详情不显示对话出处**：移除正文下方的 provenance 列表；搜索结果的「有出处/无出处」标签一并移除。数据仍保留在 API/导出/审计里，只是 UI 不展示。
3. 出处的可核验性不再作为列表信息；需要看证据时走导出或后续「高级」入口（V3.3 再评估）。

## 被否方案

- **继续用暖灰/靛蓝**：用户明确觉得违和；Chrome 的中性灰更贴近桌面应用。
- **保留出处但折叠**：当前没有「高级」入口，折叠也会增加一个可点项；先直接移除。
- **给三类色重新设计一套品牌色**：V3.3 视觉基线再评估，当前以 Chrome 为准。

## 证据

- `ci` 全绿：**249 个测试**。`S16.1` 增加 Chrome 具体色值断言；`S13.1` 增加「不出现 `detail.data.provenance` / `provenance_verifiable`」断言。
- 构建产物重新生成；详情卡只保留序号/类型/维护者/日期、正文、修订/删除/收起。

## 偏差与回滚

- 出处数据仍可被导出和 `memory_read` 看到，只是 GUI 不展示。
- Chrome 深色 `#202124` 与宿主 DSH 深色可能略有差异，这是独立视觉的预期。
- 回滚：恢复 ADR-0026 的暖灰/靛蓝令牌，恢复详情 provenance 列表与搜索标签。
